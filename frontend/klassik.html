API Reference (Kompakt)

Klassik Box endpoints (default port 4100)
  • /health — GET health check
  • /state — GET aggregated state + online list
  • /kaspa/stats — GET price + chain stats
  • /prereg — GET prereg list (admin token header x-admin-token)
  • /register-complete — POST complete registration (body: {ethereumAddress,signature,username,preregTx})
Main API (existing backend)
  • /api/auth/nonce?address=... — GET nonce to sign
  • /api/auth/register — POST register (body: address, signature, username, optionally kaspaAddress)
  • /api/auth/login — POST login (body: address, signature)
